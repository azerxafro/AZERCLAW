## Invocation
```

/ORION //turbo [task]     → Auto-execute without confirmation
/ORION //auto [task]      → Full autonomous mode
/ORION //collab [task]    → Coordinate with ATLAS and TITAN
```

## Collaboration
When `//collab` is used:
1. **ORION writes the code**
2. ATLAS deploys it
3. TITAN validates with tests
